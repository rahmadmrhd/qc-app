# QC App — panduan untuk agen

Aplikasi Quality Control: backend Google Apps Script (GAS) + Google Sheets, frontend React single-file yang disajikan GAS.
PRD: `docs/prd/`. Rencana implementasi: `docs/superpowers/plans/`.

## Perintah
- `bun run dev` — Worker lokal (`wrangler dev --local`, D1 lokal, :8787) + Vite (:3000) yang mem-proxy `/api`, `/auth`, `/sync` ke Worker. Mock backend di peramban sudah dihapus. Sekali di awal: `bun run db:seed` (migrasi + data contoh ke D1 lokal); login lewat "Masuk sebagai pengguna dev" (`DEV_LOGIN_EMAIL` di `worker/.dev.vars`). Jembatan Google tidak tersedia lokal. Rincian: `docs/dev-worker.md`.
- `bun run check` — typecheck + Biome + semua test. Wajib hijau sebelum commit.
- `bun run build` — build web (Vite, potongan JS/CSS dengan lazy load per rute) ke `worker/dist` (aset statis Worker), lalu `verify-dist`: `index.html` ada, tanpa kode mock, dan tiap potongan JS ≤ 600 KB gzip. Aplikasi Apps Script lama: `bun run build:gas` (`gas/dist` + `verify-gas-dist`); jembatan: `bun run build:bridge`.
- `bun run push` / `bun run deploy` — push ke Apps Script / perbarui deployment tetap (`gas/deployment.json`).
- Bun terpasang di `~/.bun/bin`; bila `bun` tidak ditemukan di shell, tambahkan ke PATH.

## Struktur
- `shared/` — kontrak FE↔GAS (`rpc.ts`) dan model permission. Murni, tanpa API GAS/DOM, import internal relatif.
- `gas/src/` — backend. `main.ts` (doGet, api, setup), `routes.ts`, `core/`, `modules/<modul>/{repo,context,validate,service,routes}.ts`.
- `gas/test-support/` — memory platform & fixture (dipakai test dan mock FE; tidak di-build).
- `web/src/` — `modules/<modul>/` (queries, schemas, components), `routes/` (tipis), `app/` (shell, router, boot), `lib/rpc/`, `modules/theme/` (terang/gelap/sistem).
- `web/src/modules/location/` — lokasi aktif (konteks, pemilih header multi-select) dan `LocationField` untuk form tulis modul berlokasi.
- `web/src/modules/files/` — kecilkan/unggah/tampil gambar (RPC `files.*`); `web/src/modules/markdown/` — render Markdown aman dan editor dengan sisip gambar. Drive hanya lewat `platform_()`.
- `gas/src/modules/sync/` — jalur sinkronisasi QC Desktop (`doPost`): token bersama + pembatas, tabel rute sinkron `getSyncRoutes_` (terpisah dari `getRoutes_`), `sync_state`/`nextRev_` (penghitung revisi; pemanggil memegang lock), sumber daya `brands` dan `items`. Kontrak: `docs/api/desktop-sync.md`. Perubahan field sinkron item/merk WAJIB menaikkan `sync_rev` (lihat `itemSyncSignature_`).
- `web/src/modules/brand/` — halaman Merk (master merk; nama merk dipakai item lewat `brand_id`). Backend: `gas/src/modules/brand/`. Izin memakai modul `item`.
- `web/src/modules/customer/` dan `gas/src/modules/customer/` — master customer (dibuat inline saat task disimpan; halaman hanya ganti nama/status). `web/src/modules/handover/` dan `gas/src/modules/handover/` — Serah Terima WH→QC dan pengerjaan QC. Task berbasis **catatan** (Markdown, maks. 5.000 karakter; tanpa item katalog, qty, atau `handover_lines`). Fungsi murni: `shared/handover.ts` (status turunan dari centang, nomor `ST-YYYYMMDD-NNN`), `shared/handover-paste.ts` (konversi tempelan WhatsApp menjadi checklist dan pemecah batch), `shared/handover-checklist.ts` (model checklist dan pencocokan centang), `shared/handover-comments.ts` (jangkar komentar), `shared/handover-text.ts` (`handoverCanonicalText`: bentuk kanonis teks butir untuk pencocokan centang), dan `shared/suggest.ts` (saran customer toleran typo/urutan kata, nama mirip). RPC `handovers.*` berlokasi: `board`, `get`, `options`, `save`, `saveBatch` (Worker: maks. 10 task per permintaan, `HANDOVER_WORKER_BATCH`; formulir bulk menampung 30 kartu dan mengirim berurutan per 10, kelompok yang sudah tersimpan dibuang dari draf bila kelompok berikutnya gagal; GAS tetap 30), `cancel`, `reopen` (hanya task Dibatalkan, `handover: manage`), `setCheck`, `setDone` (tanpa field `done`; hanya menyelesaikan), `comment` (komentar umum memakai `quote: ''`; baca `anyOf` WH/QC; tulis `locationId` + `id`, lokasi baris diperiksa ulang). Batas: catatan 5.000 karakter, 300 butir checklist, komentar 1.000 karakter, 50 komentar atau 40.000 karakter JSON per task (mana lebih dulu). Editor catatan: `NoteEditor` (`web/src/modules/handover/components/note-editor.tsx`) memakai `wysiwyg-editor.tsx` (Tiptap) lewat `extraExtensions`; konversi WhatsApp lewat `whatsappPasteExtension` (`web/src/modules/handover/lib/paste-extension.ts`), bukan mode `WysiwygEditor`; tampilan baca, centang, dan komentar di `note-view.tsx`. Kanban (desktop) dan kartu (ponsel) ada di `web/src/modules/handover/components/`.
- `shared/qrcode.ts` — tata letak label QR murni (`layoutLabel`, sel lembar 10×14, hash/status ekspor); `web/src/modules/qrcode/` — halaman QR Code (form + pratinjau 3×3, dialog pratinjau lembar, ekspor PDF/PNG di FE dengan `pdf-lib`, label dipakai ulang 140× lewat `embedPdf`); `gas/src/modules/qrcode/` — konfigurasi (`qr_designs`), PDF sumber (`qr_documents`, dibagikan "siapa saja yang punya link"), ekspor ke folder Drive `QR_FOLDER_ID` dan folder dokumen `QR_DOC_FOLDER_ID`. Izin modul `qrcode` (global). `cleanupQrPdfs` (publik di `main.ts`, khusus pemilik) adalah pembersih terjadwal untuk trigger waktu Apps Script (`docs/setup-google.md` 7d). Logo memakai pemilik berkas `qrlogo/shared` (boleh dirujuk banyak konfigurasi); banyak konfigurasi default QR (`qr_presets`, `/qrcode/default`, izin kelola; wajib dipilih saat membuat QR baru) dan satu pustaka logo bersama (`qr_defaults`) — user QR hanya memilih logo dari pustaka. Ekspor butuh izin edit; hapus dan pengaturan default butuh kelola. Satu PDF sumber hanya untuk satu konfigurasi QR (tanpa fitur duplikat; unggah ulang selalu mengganti isi, URL tetap); luas logo beserta latarnya maks. 15% luas QR. PRD: `docs/prd/2026-10-16-qc-qr-code.md`.
- `web/src/modules/item/` — Data Item (daftar, form, detail); detail Markdown dan gambar memakai `modules/markdown` dan `modules/files`. Backend: `gas/src/modules/item/`; fungsi murni (kunci pencarian, hash, rujukan berkas) di `shared/items.ts`.

## Aturan Worker (CPU edge dan rows read D1)
- Gerbang rilis: p95 <= 8 ms CPU per rute di edge dan 100 sampel per rute (`worker/scripts/load-cpu.ts`, hanya staging). Tiap round trip D1 menelan ±0,5-0,8 ms CPU: gabungkan kueri dengan `db.batch()` dan jangan membaca ulang apa yang sudah dimuat (`worker/scripts/hot-path.test.ts` menjaga round trip per rute dan melarang `SCAN` tabel besar di rute panas).
- Rows read D1 dihitung dari baris yang DIPINDAI (kuota 5 juta/hari), bukan yang dikembalikan: jangan memakai `instr`/`LIKE`/`COUNT(*) GROUP BY` pada tabel besar di rute panas. Keunikan dan pencarian nama lain item lewat tabel `item_alias_keys` (PRIMARY KEY), jumlah item per merk lewat kolom `brands.item_count`; keduanya WAJIB ditulis bersama `items` (`insertItemStmts`/`updateItemStmts`, skrip impor `scripts/migrate`). Tiap indeks baru menambah 1 baris ditulis per tulis (kuota 100 ribu/hari).
- Cache memori isolate (`worker/src/core/mem-cache.ts`, TTL bawaan 10 dtk, maks. 15 dtk, `CACHE_TTL_MS=0` mematikan): konteks akses, daftar lokasi, `brands`, `customers`. Pernyataan tulis ke tabel itu memanggil `touchCache(kelompok)` saat disusun (di builder repo) dan `settleCache()` dibuang di akhir permintaan; jalur yang memutuskan penulisan (sinkron, ganti nama/status merk dan customer) memakai `{ fresh: true }`. Tes memakai `CACHE_TTL_MS=0` secara bawaan; jalankan `QC_TEST_CACHE_TTL_MS=10000 bun test` di `worker/` untuk memeriksa invalidasi (hanya tes yang menyuntik SQL mentah dan memanggil `env.DB.batch` di luar permintaan yang boleh gagal).
- Isi berkas dibaca lewat `cachedFileContent` (`worker/src/core/file-cache.ts`): R2 opsional (`FILES_CACHE`, objek `f/<driveId>`), lalu jembatan. Izin/folder diperiksa SEBELUM cache; setiap `trashFile`/`replaceFileContent` baru wajib diikuti `dropCachedFile`.
- Parsing checklist catatan memakai `worker/src/modules/handover/checklist.ts` (memo kecil per isolate) dan `matchChecksToEntries`; jangan memanggil `extractChecklist`/`matchChecks` berulang per baris.

## Aturan kode GAS (ditegakkan `scripts/build-gas.ts`)
- File di-transpile per file dan `import`/`export` dihapus: semua file berbagi SATU global scope.
- Semua fungsi top-level di `gas/src` WAJIB berakhiran `_` (agar tidak bisa dipanggil via `google.script.run`), kecuali `doGet`, `api`, `setup`.
- Pengecualian terdokumentasi: fungsi murni di `shared/` tidak berakhiran `_` (tidak menyentuh data/API GAS; lihat PRD NFR-2).
- Nama top-level unik di seluruh `gas/src` + `shared/`. Dilarang: `export default`, re-export, import alias/namespace/dynamic, class, enum.
- Tidak ada kode top-level yang memakai global file lain saat load — bungkus dalam fungsi (lihat `getRoutes_`).
- Akses API GAS hanya lewat `platform_()`; implementasi asli di `core/gas-platform.ts`.
- Tulis ke sheet di dalam `platform_().withLock(...)`; teks disimpan lewat `core/db` (aman dari formula injection).
- Performa: tiap panggilan Sheets/Drive berbiaya ratusan ms dan tiap eksekusi Apps Script punya biaya tetap 1,5–2,5 dtk. `handleRpc_`/`handleRpcBatch_`/`handleSync_`/`doGet` membungkus permintaan dengan `withRequestCache_` (cache baca-tabel per permintaan di `core/db`: disalin saat dibaca, dibuang saat tulis lewat `core/db` dan saat masuk/keluar `withLock`) — jangan menulis ke sheet di luar `core/db`. Frontend: `defaultPreload: false` (prefetch hover mengantre RPC `google.script.run` dan memblokir klik nyata); `gas-transport` menggabungkan RPC yang dipicu dalam jendela 15 ms menjadi SATU `api('batch', ...)` (maks. 8 item, tiap item tetap lewat `handleRpc_` penuh; payload > 20 ribu karakter dikirim sendiri), jadi loader yang butuh beberapa query harus memicunya bersamaan (`Promise.all`), bukan berurutan.
- Cache data (server): `readTable_` berlapis — cache permintaan, lalu cache lintas request `CacheService` untuk tabel bertanda `sharedCache: true` di `TableSchema` (brands, customers, qr_defaults, qr_presets — BUKAN users/roles/locations: tabel sumber akses sudah punya cache konteks `uctx`, menumpuk dua cache menunda pencabutan akses hingga ±10 menit; versi per tabel `tblv:<sheet>` diganti saat tulis DAN lagi sesudah `flush` di akhir lock lewat `finishLockWrites_`; TTL 5 menit sehingga suntingan manual di Sheets tampak ≤ 5 menit; > 90 KB tidak di-cache), lalu Sheets dalam SATU panggilan (`getDataRange`). Tulis lewat `core/db` memperbarui cache permintaan di tempat. `setup` memformat semua kolom sebagai teks dan menyetel Script Property `TEXT_FORMATS_V1` (jalankan `setup` setelah deploy); selama belum ada, tulis tetap memformat per baris. Log audit dibaca per halaman (`readAuditPage_`), isi berkas ≤ 540 KB di-cache per potongan di `CacheService` (`fcont:<folderId>:<driveId>`, TTL 3 jam, terikat folder aktif) setelah pemeriksaan izin. Tes yang menyuntik baris mentah ke tabel `sharedCache` harus memanggil `bumpTableVersion_`.
- Cache data (frontend): mutasi QR dan item memasang hasil server langsung ke cache (`web/src/lib/query-cache.ts`: `upsertInList`, `removeFromList`, `markStale`) dan TIDAK menunggu muat ulang (sebelumnya simpan + muat ulang daftar berurutan); `app/prefetch.ts` mem-prefetch daftar yang boleh dibaca sekali saat beranda diam (batch); `app/query-persist.ts` menyimpan query whitelist (me, items, brands, qrcodes) di localStorage per pemilik token, dipulihkan sebelum router dibuat (tampil instan lalu dimuat ulang), dibuang saat keluar. Jangan menambah Log Audit, user, atau isi berkas ke whitelist.
- Jangan pakai API JS yang runtime V8 Apps Script belum tentu dukung (mis. `Object.hasOwn`); aturan Biome `noPrototypeBuiltins` sengaja dimatikan.
- Build menolak API yang TIDAK ada di runtime GAS (`URL`, `URLSearchParams`, `fetch`, `setTimeout`, `atob`/`btoa`, `structuredClone`, `TextEncoder`, `Buffer`, `window`, dll.; daftar + penggantinya di `scripts/build-gas-lib.ts`) di `gas/src` dan `shared/`. Bun/Node/peramban menyediakannya sehingga tes tetap hijau padahal produksi gagal (mis. `new URL` melempar ReferenceError). Gunakan padanan yang disarankan pesan galat.
- Karakter khusus (mis. U+2028) ditulis lewat `String.fromCharCode`, bukan literal/escape di regex.
- Konstanta level atas tidak boleh memakai global file lain (mis. `SYNC_ACTOR`); `verify-dist` memuat semua file `gas/dist` dalam urutan maju dan mundur untuk menangkapnya. Nama top-level harus unik juga terhadap `shared/` (beri awalan modul, mis. `QR_STALE_MESSAGE`).
- Jangan pernah mengedit `gas/dist/` manual.

## Aturan frontend
- Komponen UI dari shadcn (`web/src/components/ui`, dikecualikan dari lint). Tambah lewat `bunx --bun shadcn@latest add <komponen>` dari folder `web/`. shadcn 4 memakai paket `cn` (shadcn-ui/cn), bukan `clsx`+`tailwind-merge`.
- Server state: TanStack Query; form: TanStack Form + zod; filter/halaman: search params Router. Tanpa library state global.
- Tema: `modules/theme` (kelas `dark` di `<html>`); skrip anti-kedip di `web/index.html` harus selaras dengan `theme.ts`.
- Jangan menaruh kode mock di build produksi (dicek `scripts/verify-dist.ts`).

## Menambah method RPC
1. Tambah entri di `RpcContract` (`shared/rpc.ts`).
2. Validator + handler di `gas/src/modules/<modul>/`, daftarkan di `<modul>/routes.ts` dengan `permission` yang tepat.
3. `getRoutes_` bertipe `RouteTable` — typecheck gagal bila method belum terdaftar.
4. FE: `queryOptions`/mutation di `web/src/modules/<modul>/queries.ts`.
5. Modul berlokasi: tandai `scope: 'location'` pada izin rute dan pakai `ctx.locationIds` (lihat `docs/adding-a-module.md`). Izin "salah satu dari": pakai `anyOf` (lihat `docs/adding-a-module.md`).

Resep modul baru: `docs/adding-a-module.md`.

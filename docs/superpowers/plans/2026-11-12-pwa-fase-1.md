# PWA Fase 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** QC App dapat dipasang (Android, iOS, desktop), cangkang aplikasinya dipra-cache service worker, dan versi baru diperbarui atas persetujuan pengguna tanpa menghilangkan isian yang belum disimpan.

**Architecture:** `vite-plugin-pwa` (Workbox `generateSW`, `registerType: 'prompt'`) membangkitkan `sw.js` dan `manifest.webmanifest` ke `server/dist`; opsinya hidup di satu berkas (`web/src/app/pwa/pwa-config.ts`) agar mudah dikembangkan (titik perluasan `workbox.importScripts`). Server Bun melayani `sw.js`/manifest sebagai berkas statis `no-cache` (sudah begitu lewat `static.ts`, ditegakkan tes). Frontend mendaftarkan service worker, memeriksa pembaruan, menampilkan spanduk, dan menyediakan butir "Pasang aplikasi". `scripts/verify-dist.ts` menegakkan isi build (manifest, ikon, denylist, anggaran).

**Tech Stack:** Vite 8, `vite-plugin-pwa` 2.0.0 (dipin; terbit 2026-10-03), `workbox-build` 7.4.1 dan `workbox-window` 7.4.1 (dipin; terbit 2026-05-04), React 19, vitest (web), `bun:test` (server dan scripts).

**Spec:** `docs/prd/2026-10-26-qc-pwa.md` (Fase 1: §4.1–4.3 FR-P1–P14, §5 NFR-P1–P7, §6.1–6.2, §7, DoD §9). Fase 2 (§4.4, FR-P15–P19) TIDAK dikerjakan. Jangan mengedit PRD §2.3 dan §12 butir 5 (milik sesi lain).

## Global Constraints

- Service worker TIDAK BOLEH menjawab `/api/*`, `/auth/*`, `/sync` dari cache atau `index.html`; navigasi `/auth/callback` tidak pernah dijawab `index.html` (FR-P8).
- Tetap `generateSW`; JANGAN beralih ke `injectManifest` dan JANGAN menaruh kode push apa pun.
- Manifest: `name` "QC App", `short_name` "QC", `lang` `id`, `start_url` `/`, `scope` `/`, `display` `standalone`, `theme_color` = `background_color` = `THEME_COLORS.light` (FR-P1).
- Ikon: PNG 192×192 dan 512×512 (`any`), 512×512 `maskable`, `apple-touch-icon` 180×180, favicon (FR-P2). Ikon sementara = monogram "QC", mudah diganti logo resmi.
- `registerType: 'prompt'`: versi baru tidak mengambil alih halaman sebelum pengguna menekan "Muat ulang" (FR-P12). Pemeriksaan pembaruan: saat dibuka, saat kembali fokus, berkala ≤ 1 jam (FR-P11).
- `/sw.js` dan `/manifest.webmanifest` dilayani `Cache-Control: no-cache` (FR-P10); `Content-Type` manifest `application/manifest+json`.
- Anggaran pra-cache ≤ 5 MB tidak terkompres (NFR-P2); potongan berat (QR/`pdf-lib`) tidak dipra-cache, dicache saat pertama dipakai (`CacheFirst`, FR-P9).
- Dependensi baru hanya `vite-plugin-pwa` (+ peer Workbox) dengan versi dipin eksak (tanpa `^`), umur ≥ 2 minggu (NFR-P7). Tanpa pustaka state global.
- Teks UI berbahasa Indonesia; spanduk dan dialog tanpa gulir horizontal di ponsel (NFR-P5).
- Skrip anti-kedip di `web/index.html` harus selaras dengan `web/src/modules/theme/theme.ts`.
- Aturan repo: field pilihan memakai `Select`/`LinkField` (tidak ada `<select>`); dialog memakai `ui/dialog`; teks tes dan komentar bahasa Indonesia; Biome (`bunx biome check --write <berkas>`) sebelum commit.
- Titik singgung sesi lain: `web/vite.config.ts`, `web/index.html`, `CLAUDE.md`. Ubah sekecil mungkin.
- Tes server: `QC_TEST_SHARDS=1`; jangan memulai/mematikan terowongan DB atau server dev. Tanpa push, tanpa PR.

## Review Focus

Masukan/kondisi yang tersirat spek tetapi tidak jelas dimiliki satu FR; tiap butir punya tesnya di task pemiliknya:

1. Navigasi `/auth/callback?code=…&state=…`, `/auth/login`, `/api/ping`, `/sync` tidak dijawab `index.html`, sedangkan `/`, `/?authError=x`, `/handover?x=1` tetap dijawab cangkang (Task 3, Task 5).
2. Navigasi ke berkas berekstensi (`/sw.js`, `/manifest.webmanifest`, `/icons/x.png`) tidak dijawab `index.html` (Task 3, Task 5).
3. Tema tersimpan `dark` saat OS terang (dan sebaliknya): `theme-color` benar sejak paint pertama dan ikut berubah saat tema diganti di dalam aplikasi (Task 1).
4. `registration.update()` gagal/offline, atau peramban tanpa `serviceWorker`, tidak melempar galat dan tidak merusak aplikasi (Task 7).
5. Dua formulir kotor lalu satu ditutup: spanduk tetap menyebut ada perubahan belum disimpan; `beforeinstallprompt` yang datang sebelum React render tidak hilang (Task 6, Task 8).

# Generator QR Code Label — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pengguna membuat konfigurasi label QR 3×3 cm (title, subtitle, QR + logo, footer) dari sebuah link atau PDF yang diunggah ke Drive, melihat pratinjaunya realtime, lalu mengekspor PDF lembar 300×420 mm (10×14, garis potong) dan PNG ke folder Drive terpisah setelah konfirmasi.

**Architecture:** Satu fungsi tata letak murni di `shared/qrcode.ts` (`layoutLabel`) dipakai tiga keluaran FE: pratinjau canvas, PNG (canvas), dan PDF (`pdf-lib`, label dibuat sekali lalu dipakai ulang 140 kali lewat `embedPdf`). Backend GAS hanya menyimpan konfigurasi (`qr_designs`), dokumen PDF sumber (`qr_documents`), dan berkas hasil ekspor di dua folder Drive baru; izin lewat modul global baru `qrcode`.

**Tech Stack:** Bun, TypeScript, GAS + Sheets, React 19 + TanStack (Query/Router/Form) + zod + shadcn, Tailwind v4, `uqr` (matriks QR), `pdf-lib` + `@pdf-lib/fontkit`, `@fontsource/poppins` (woff), `jsqr` (tes decode).

**Spec:** `docs/prd/2026-10-16-qc-qr-code.md`

## Rulings terhadap spek (dibuat saat menulis rencana)

- **R1 — rujukan PDF sumber lewat `qr_documents`.** Spek §6.1 menaruh `pdf_drive_id` di `qr_designs`, tetapi NFR7 melarang id Drive datang dari klien. Maka PDF sumber dicatat di sheet `qr_documents` (`id` uuid, `drive_id`, `name`, …) dan konfigurasi merujuk `document_id`. Klien hanya melihat uuid. Biaya bila salah: satu sheet tambahan.
- **R2 — logo bersama tanpa mengubah `attachFiles_`.** Logo diklaim dengan `attachFiles_([id], 'qrlogo', 'shared')`: pemilik `qrlogo`/`shared` konstan sehingga banyak konfigurasi boleh merujuk berkas yang sama. `FileOwnerType` bertambah `'qrlogo'`.
- **R3 — `files.upload`/`files.get` jadi `anyOf` (`item` ATAU `qrcode`).** Pengguna `qrcode` tanpa izin `item` tetap dapat mengunggah dan menampilkan logo.
- **R4 — peringatan QR terlalu padat (non-blokir).** Modul QR < 0,30 mm (link panjang di QR kecil) sulit dicetak/dipindai; form memperingatkan tetapi tidak memblokir (hanya overflow yang memblokir ekspor).
- **R5 — karakter teks dibatasi ke set yang dicakup font Poppins latin** (U+0020–00FF dan beberapa tanda baca umum); selain itu ditolak validator dan skema form, agar PDF/PNG tidak menampilkan kotak kosong.
- **R7 — nilai bawaan ukuran diturunkan dari usulan PRD §11** (title 7 pt, QR 20 mm, dst. tidak muat bersama subtitle dan footer: total ≈ 34 mm). Bawaan baru: title 6 pt, subtitle 5 pt, footer 4 pt, QR 17 mm, logo 22%, jarak 1 mm, padding 1,2 mm (total ≈ 29,0 mm); tetap dapat diatur per bagian. Biaya bila salah: hanya nilai awal form.
- **R6 — Poppins dipakai** (mirip contoh). Font di-bundle sebagai woff (inline lewat `?url`); batas ukuran `index.html` di `scripts/verify-dist.ts` dinaikkan secukupnya bila bundel melewati 1,5 MB (Task 9).

## Review Focus

Masukan/kondisi yang tidak dicakup spek secara eksplisit tetapi paling mungkin merugikan pengguna (tiap butir punya tes di task pemiliknya):

1. **Link terlalu panjang pada QR kecil** → matriks padat, modul < 0,3 mm, tidak terbaca saat dicetak. Harapan: peringatan jelas (R4). — Task 2 (`tooDense`), Task 11.
2. **Teks sangat panjang / satu kata tanpa spasi / karakter di luar font** → teks terpotong atau kotak kosong. Harapan: overflow terdeteksi, ekspor diblokir; karakter tak didukung ditolak. — Task 2, Task 5, Task 10.
3. **Dua orang mengubah/mengekspor konfigurasi yang sama** → ekspor berisi versi basi atau menimpa ubahan. Harapan: `CONFLICT` (`expectedUpdatedAt`). — Task 6, Task 8.
4. **Ekspor gagal di tengah (Drive berhasil, pencatatan gagal) atau ekspor ulang** → berkas yatim, atau berkas lama hilang padahal baru gagal tercatat. Harapan: berkas baru dibersihkan bila gagal; berkas lama baru dibuang setelah pencatatan sukses. — Task 8.
5. **Mengganti/menghapus sesuatu yang dipakai bersama** (PDF dipakai beberapa konfigurasi; logo bersama; menghapus konfigurasi) → label tercetak rusak atau konfigurasi lain ikut kehilangan logo. Harapan: URL PDF tetap sama; hapus tidak membuang PDF/logo. — Task 6, Task 7.

```ts
import { hashText } from './items';

export const QR_LIMITS = {
  title: 60,
  subtitle: 80,
  footer: 80,
  link: 300,
  documentName: 150,
  documentMaxBytes: 10 * 1024 * 1024,
  exportMaxBytes: 8 * 1024 * 1024,
} as const;

export const LABEL_MM = 30;
export const SHEET = { widthMm: 300, heightMm: 420, columns: 10, rows: 14 } as const;
export const PT_PER_MM = 72 / 25.4;
/** Modul QR lebih kecil dari ini sulit dicetak dan dipindai. */
export const MIN_MODULE_MM = 0.3;
const QR_LINE_HEIGHT = 1.25;

export type QrLinkSource = 'url' | 'pdf';
export type QrExportStatus = 'none' | 'current' | 'stale';

export interface QrLayout {
  /** Ukuran font dalam pt. */
  titleSize: number;
  subtitleSize: number;
  footerSize: number;
  /** Sisi QR dalam mm. */
  qrSize: number;
  /** Sisi logo sebagai persen sisi QR. */
  logoPercent: number;
  /** Jarak antarbagian dan padding kanvas dalam mm. */
  gap: number;
  padding: number;
}

export const QR_LAYOUT_KEYS = [
  'titleSize',
  'subtitleSize',
  'footerSize',
  'qrSize',
  'logoPercent',
  'gap',
  'padding',
] as const;

export const QR_LAYOUT_RANGES: Record<
  keyof QrLayout,
  { min: number; max: number; step: number; unit: 'pt' | 'mm' | '%'; label: string }
> = {
  titleSize: { min: 4, max: 14, step: 0.5, unit: 'pt', label: 'Ukuran title' },
  subtitleSize: { min: 3, max: 12, step: 0.5, unit: 'pt', label: 'Ukuran subtitle' },
  footerSize: { min: 3, max: 10, step: 0.5, unit: 'pt', label: 'Ukuran footer' },
  qrSize: { min: 10, max: 26, step: 0.5, unit: 'mm', label: 'Ukuran QR' },
  logoPercent: { min: 8, max: 30, step: 1, unit: '%', label: 'Ukuran logo' },
  gap: { min: 0, max: 5, step: 0.1, unit: 'mm', label: 'Jarak antarbagian' },
  padding: { min: 0, max: 5, step: 0.1, unit: 'mm', label: 'Padding kanvas' },
};

/** Total tinggi bila title, subtitle, dan footer masing-masing satu baris ≈ 29,0 mm dari 30 mm. */
export const DEFAULT_QR_LAYOUT: QrLayout = {
  titleSize: 6,
  subtitleSize: 5,
  footerSize: 4,
  qrSize: 17,
  logoPercent: 22,
  gap: 1,
  padding: 1.2,
};

export function isQrLayout(value: unknown): value is QrLayout {
  if (typeof value !== 'object' || value === null) return false;
  const record = value as Record<string, unknown>;
  return QR_LAYOUT_KEYS.every((key) => {
    const entry = record[key];
    const range = QR_LAYOUT_RANGES[key];
    return typeof entry === 'number' && Number.isFinite(entry) && entry >= range.min && entry <= range.max;
  });
}

/** Menyaring nilai tersimpan/tak tepercaya: tiap field dijepit ke rentang; yang bukan angka memakai bawaan. */
export function clampQrLayout(value: Partial<Record<string, unknown>>): QrLayout {
  const out: QrLayout = { ...DEFAULT_QR_LAYOUT };
  for (const key of QR_LAYOUT_KEYS) {
    const entry = value[key];
    if (typeof entry !== 'number' || !Number.isFinite(entry)) continue;
    const range = QR_LAYOUT_RANGES[key];
    out[key] = Math.min(range.max, Math.max(range.min, entry));
  }
  return out;
}

export function isHttpUrl(text: string): boolean {
  return /^https?:\/\/[^\s]+$/i.test(text);
}

const QR_EXTRA_ALLOWED_CODES = [0x131, 0x152, 0x153, 0x2bb, 0x2bc, 0x2c6, 0x2da, 0x2dc, 0x20ac, 0x2122, 0x2212];

/** Karakter yang dicakup font label (Poppins latin): satu baris, tanpa kontrol. */
export function isRenderableLabelText(text: string): boolean {
  for (const ch of text) {
    const code = ch.codePointAt(0) ?? 0;
    const ok =
      (code >= 0x20 && code <= 0x7e) ||
      (code >= 0xa0 && code <= 0xff) ||
      (code >= 0x2010 && code <= 0x2027) ||
      QR_EXTRA_ALLOWED_CODES.includes(code);
    if (!ok) return false;
  }
  return true;
}

export function driveShareUrl(fileId: string): string {
  return `https://drive.google.com/file/d/${fileId}/view`;
}

export function labelFileSlug(title: string): string {
  const slug = title
    .toLowerCase()
    .replace(/[^a-z0-9]+/g, '-')
    .replace(/^-+|-+$/g, '')
    .slice(0, 40)
    .replace(/-+$/g, '');
  return slug === '' ? 'label' : slug;
}

  hasLogo: boolean;
  layout: QrLayout;
  /** Jumlah modul per sisi matriks QR (untuk ukuran modul). */
  qrModules: number;
}

export interface LabelLayout {
  elements: LabelElement[];
  /** Isi tidak muat di kanvas 30 × 30 mm: ekspor harus diblokir. */
  overflow: boolean;
  moduleMm: number;
  /** Modul < `MIN_MODULE_MM`: peringatan saja. */
  tooDense: boolean;
}

function wrapLabelText(
  text: string,
  maxMm: number,
  sizePt: number,
  bold: boolean,
  measure: Measure,
): { lines: string[]; tooWide: boolean } {
  const lines: string[] = [];
  let tooWide = false;
  let line = '';
  for (const word of text.split(' ').filter((w) => w !== '')) {
    const candidate = line === '' ? word : `${line} ${word}`;
    if (measure(candidate, sizePt, bold) <= maxMm) {
      line = candidate;
      continue;
    }
    if (line !== '') lines.push(line);
    line = word;
    if (measure(word, sizePt, bold) > maxMm) tooWide = true;
  }
  if (line !== '') lines.push(line);
  return { lines, tooWide };
}

interface Block {
  role: LabelRole;
  lines: string[];
  sizePt: number;
  bold: boolean;
  heightMm: number;
}

function toLabelBlock(
  role: LabelRole,
  text: string,
  sizePt: number,
  bold: boolean,
  maxMm: number,
  measure: Measure,
): { block: Block | null; tooWide: boolean } {
  if (text.trim() === '') return { block: null, tooWide: false };
  const { lines, tooWide } = wrapLabelText(text.trim(), maxMm, sizePt, bold, measure);
  const heightMm = (lines.length * sizePt * QR_LINE_HEIGHT) / PT_PER_MM;
  return { block: { role, lines, sizePt, bold, heightMm }, tooWide };
}

function labelTextElements(block: Block, topMm: number): LabelElement[] {
  const sizeMm = block.sizePt / PT_PER_MM;
  return block.lines.map((text, index): LabelElement => ({
    kind: 'text',
    role: block.role,
    text,
    centerMm: LABEL_MM / 2,
    baselineMm: topMm + (index * QR_LINE_HEIGHT + 1) * sizeMm,
    sizePt: block.sizePt,
    bold: block.bold,
  }));
}

/**
 * Menyusun elemen label (satuan mm, pojok kiri atas): title dan subtitle di atas, footer menempel di dasar,
 * QR di tengah ruang tersisa. Fungsi murni: pratinjau, PNG, dan PDF memakai hasil yang sama.
 */
export function layoutLabel(input: LabelInput, measure: Measure): LabelLayout {
  const { layout } = input;
  const innerW = LABEL_MM - 2 * layout.padding;
  const title = toLabelBlock('title', input.title, layout.titleSize, true, innerW, measure);
  const subtitle = toLabelBlock('subtitle', input.subtitle, layout.subtitleSize, false, innerW, measure);
  const footer = toLabelBlock('footer', input.footer, layout.footerSize, false, innerW, measure);
  const elements: LabelElement[] = [];
  let y = layout.padding;
  let headerExists = false;
  for (const entry of [title, subtitle]) {
    if (!entry.block) continue;
    if (headerExists) y += layout.gap;
    elements.push(...labelTextElements(entry.block, y));
    y += entry.block.heightMm;
    headerExists = true;
  }
  const headerBottom = y;
  const footerTop = footer.block
    ? LABEL_MM - layout.padding - footer.block.heightMm
    : LABEL_MM - layout.padding;
  if (footer.block) elements.push(...labelTextElements(footer.block, footerTop));
  const gapAbove = headerExists ? layout.gap : 0;
  const gapBelow = footer.block ? layout.gap : 0;
  const available = footerTop - headerBottom - gapAbove - gapBelow;
  const qrSize = layout.qrSize;
  const qrY = headerBottom + gapAbove + Math.max(0, (available - qrSize) / 2);
  const qrX = (LABEL_MM - qrSize) / 2;
  elements.push({ kind: 'qr', xMm: qrX, yMm: qrY, sizeMm: qrSize });
  if (input.hasLogo) {
    const size = (qrSize * layout.logoPercent) / 100;
    const centerY = qrY + qrSize / 2;
    elements.push({
      kind: 'logo',
      xMm: LABEL_MM / 2 - size / 2,
      yMm: centerY - size / 2,
      sizeMm: size,
      backdropMm: size * 1.15,
    });
  }
  const overflow =
    title.tooWide ||
    subtitle.tooWide ||
    footer.tooWide ||
    qrSize > innerW + 1e-9 ||
    available < qrSize - 1e-9;
  const moduleMm = qrSize / Math.max(1, input.qrModules);
  return { elements, overflow, moduleMm, tooDense: moduleMm < MIN_MODULE_MM };
}

/** Sel lembar 10 × 14: pojok kiri atas tiap label, urut baris demi baris. */
export function sheetCells(): Array<{ xMm: number; yMm: number }> {
  const cells: Array<{ xMm: number; yMm: number }> = [];
  for (let row = 0; row < SHEET.rows; row++) {
    for (let column = 0; column < SHEET.columns; column++) {
      cells.push({ xMm: column * LABEL_MM, yMm: row * LABEL_MM });
    }
  }
  return cells;
}

  linkSource: QrLinkSource;
  /** Link efektif (untuk sumber `pdf`: URL berbagi berkas). */
  link: string;
  title: string;
  subtitle: string;

  logoFileId: string;
  layout: QrLayout;
}

export function qrContentHash(content: QrContent): string {
  return hashText(
    JSON.stringify([
      content.linkSource,
      content.link,
      content.title,
      content.subtitle,
      content.footer,

      QR_LAYOUT_KEYS.map((key) => content.layout[key]),
    ]),
  );
}

}
```

```ts
import { readObject_ } from '@gas/core/validate';
import { base64ByteLength, isBase64Text } from '@shared/files';
import {
  isHttpUrl,
  isQrLayout,
  isRenderableLabelText,
  QR_LIMITS,
} from '@shared/qrcode';
import type {
  ExportQrDesignInput,
  QrDesignRefInput,
  QrFileInput,
  SaveQrDesignInput,
  UploadQrPdfInput,
} from '@shared/rpc';

const QR_PDF_PREFIX = 'JVBERi0'; // "%PDF-" dalam base64
const QR_PNG_PREFIX = 'iVBORw0KGgo';
const QR_FILE_KINDS = ['pdf', 'png'] as const;
const QR_LINK_SOURCES = ['url', 'pdf'] as const;

export function validateSaveQrDesign_(raw: unknown): SaveQrDesignInput {
  const reader = readObject_(raw);
  const id = reader.optionalId('id');
  const expectedUpdatedAt = reader.optionalId('expectedUpdatedAt');
  const title = reader.str('title', { required: true, max: QR_LIMITS.title });
  const linkSource = reader.oneOf('linkSource', QR_LINK_SOURCES);
  const subtitle = reader.str('subtitle', { max: QR_LIMITS.subtitle });
  const footer = reader.str('footer', { max: QR_LIMITS.footer });
  for (const [key, text] of [['title', title], ['subtitle', subtitle], ['footer', footer]] as const) {
    if (text !== '' && !isRenderableLabelText(text)) {
      reader.fail(key, 'Karakter tidak didukung font label (gunakan huruf Latin, angka, dan tanda baca umum)');
    }
  }
  let link = '';
  let documentId = '';
  if (linkSource === 'url') {
    link = reader.str('link', { required: true, max: QR_LIMITS.link });
    if (link !== '' && !isHttpUrl(link)) reader.fail('link', 'Link harus diawali http:// atau https:// tanpa spasi');
  } else {
    documentId = reader.str('documentId', { required: true, max: 100 });
  }
  const logoFileId = reader.str('logoFileId', { max: 100 });
  const layout = reader.raw('layout');
  if (!isQrLayout(layout)) reader.fail('layout', 'Ukuran tata letak tidak valid atau di luar rentang');
  reader.done();
  const input: SaveQrDesignInput = {
    title, linkSource, link, documentId, subtitle, footer, logoFileId, layout: layout as SaveQrDesignInput['layout'],
  };
  return {
    ...(id ? { id } : {}),
    ...(expectedUpdatedAt ? { expectedUpdatedAt } : {}),
    ...input,
  };
}

export function validateQrDesignRef_(raw: unknown): QrDesignRefInput {
  const reader = readObject_(raw);
  const id = reader.str('id', { required: true, max: 100 });
  reader.done();
  return { id };
}

export function validateUploadQrPdf_(raw: unknown): UploadQrPdfInput {
  const reader = readObject_(raw);
  const name = reader.str('name', { required: true, max: QR_LIMITS.documentName });
  const replaceDocumentId = reader.optionalId('replaceDocumentId');
  const base64 = reader.raw('base64');
  if (typeof base64 !== 'string' || !isBase64Text(base64)) {
    reader.fail('base64', 'Isi berkas tidak valid');
  } else if (base64ByteLength(base64) > QR_LIMITS.documentMaxBytes) {
    reader.fail('base64', 'Ukuran PDF maksimal 10 MB');
  } else if (!base64.startsWith(QR_PDF_PREFIX)) {
    reader.fail('base64', 'Berkas bukan PDF');
  }
  reader.done();
  return { name, base64: base64 as string, ...(replaceDocumentId ? { replaceDocumentId } : {}) };
}

export function validateExportQrDesign_(raw: unknown): ExportQrDesignInput {
  const reader = readObject_(raw);
  const id = reader.str('id', { required: true, max: 100 });
  const expectedUpdatedAt = reader.str('expectedUpdatedAt', { required: true, max: 40 });
  const pdf = reader.raw('pdfBase64');
  const png = reader.raw('pngBase64');
  if (typeof pdf !== 'string' || !isBase64Text(pdf) || !pdf.startsWith(QR_PDF_PREFIX)) {
    reader.fail('pdfBase64', 'PDF tidak valid');
  }
  if (typeof png !== 'string' || !isBase64Text(png) || !png.startsWith(QR_PNG_PREFIX)) {
    reader.fail('pngBase64', 'PNG tidak valid');
  }
  if (
    typeof pdf === 'string' &&
    typeof png === 'string' &&
    base64ByteLength(pdf) + base64ByteLength(png) > QR_LIMITS.exportMaxBytes
  ) {
    reader.fail('pdfBase64', 'Ukuran hasil ekspor maksimal 8 MB');
  }
  reader.done();
  return { id, expectedUpdatedAt, pdfBase64: pdf as string, pngBase64: png as string };
}

export function validateQrFile_(raw: unknown): QrFileInput {
  const reader = readObject_(raw);
  const id = reader.str('id', { required: true, max: 100 });
  const kind = reader.oneOf('kind', QR_FILE_KINDS);
  reader.done();
  return { id, kind };
}
```

```ts
export function qrDesignContent_(

export function saveQrDesign_(input: SaveQrDesignInput, actor: ActorRef): QrDesignDto {

    const designs = listQrDesigns_();

    if (input.id && !existing) throw appError_('NOT_FOUND', 'Konfigurasi tidak ditemukan');
    if (existing && input.expectedUpdatedAt && input.expectedUpdatedAt !== existing.updatedAt) {
      throw appError_('CONFLICT', QR_STALE_MESSAGE);
    }
    const documents = qrDocumentMap_();
    if (input.linkSource === 'pdf' && !documents.has(input.documentId)) {
      const message = 'PDF tidak dikenal; unggah ulang';
      throw appError_('VALIDATION', message, { documentId: message });
    }
    const now = nowIso_();
    const next: NewQrDesignRecord = {
      id: existing?.id ?? platform_().uuid(),
      title: input.title,
      linkSource: input.linkSource,
      link: input.linkSource === 'url' ? input.link : '',
      documentId: input.linkSource === 'pdf' ? input.documentId : '',
      subtitle: input.subtitle,
      footer: input.footer,
      logoFileId: input.logoFileId,
      layout: input.layout,
      exportedHash: existing?.exportedHash ?? '',
      exportedAt: existing?.exportedAt ?? '',
      exportedBy: existing?.exportedBy ?? '',
      exportPdfDriveId: existing?.exportPdfDriveId ?? '',
      exportPngDriveId: existing?.exportPngDriveId ?? '',
      createdAt: existing?.createdAt ?? now,
      createdBy: existing?.createdBy ?? actor.email,
      updatedAt: now,
      updatedBy: actor.email,
    };
    // Logo bersama: pemilik tetap ('qrlogo','shared') agar banyak konfigurasi boleh merujuk berkas yang sama.
    if (next.logoFileId !== '') attachFiles_([next.logoFileId], 'qrlogo', 'shared');

    if (!existing) {
      insertQrDesign_(next);
      appendAudit_({
        ts: now,
        actor: actor.email,
        action: 'qrcode.create',
        target: next.title,
        before: null,
        after: qrDesignSnapshot_(next, documents),
      });
      return toQrDesignDto_(next, documents, qrUsesMap_([...designs, { ...next, rowNumber: 0 }]));
    }
    const before = qrDesignSnapshot_(existing, documents);
    const after = qrDesignSnapshot_(next, documents);
    if (JSON.stringify(before) === JSON.stringify(after)) {
      return toQrDesignDto_(existing, documents, qrUsesMap_(designs));
    }
    const saved: QrDesignRecord = { ...next, rowNumber: existing.rowNumber };
    updateQrDesign_(saved);
    appendAudit_({
      ts: now,
      actor: actor.email,
      action: 'qrcode.update',
      target: saved.title,
      before,
      after,
    });
    return toQrDesignDto_(
      saved,
      documents,
      qrUsesMap_(designs.map((row) => (row.id === saved.id ? saved : row))),
    );
  });
}

export function removeQrDesign_(input: QrDesignRefInput, actor: ActorRef): QrDesignRefInput {

      ts: nowIso_(),
      actor: actor.email,
      action: 'qrcode.delete',
      target: design.title,
      before: qrDesignSnapshot_(design, documents),
      after: null,
    });
    return design;
  });

  for (const driveId of [removed.exportPdfDriveId, removed.exportPngDriveId]) {
    if (driveId !== '') platform_().driveTrashFile(driveId);
  }
  return { id: removed.id };
}
```

```ts
export function uploadQrPdf_(input: UploadQrPdfInput, actor: ActorRef): QrDocumentDto {
  const platform = platform_();

  if (input.replaceDocumentId) {
    const current = listQrDocuments_().find((doc) => doc.id === input.replaceDocumentId);
    if (!current) throw appError_('NOT_FOUND', 'PDF tidak ditemukan');

    } catch (error) {

        after: { name: input.name, size, replaced: true },
      });
      return toQrDocumentDto_(updated, qrDocumentUses_(updated.id));
    });
  }
  const folderId = ensureQrDocFolder_();
  const driveId = platform.driveCreateFile(folderId, input.name, 'application/pdf', input.base64);
```

```ts
/** Merender matriks ke piksel RGBA (quiet zone 4 modul) untuk didecode jsQR. */
function pixels(matrix: boolean[][], scale = 6, quiet = 4, maskPercent = 0) {
  const n = matrix.length;
  const size = (n + quiet * 2) * scale;
  const data = new Uint8ClampedArray(size * size * 4).fill(255);
  const mask = (maskPercent / 100) * n;
  const lo = (n - mask) / 2;
  const hi = (n + mask) / 2;
  for (let r = 0; r < n; r++) {
    for (let c = 0; c < n; c++) {
      if (!matrix[r]?.[c]) continue;
      if (maskPercent > 0 && r >= lo && r < hi && c >= lo && c < hi) continue; // logo menutupi tengah
      for (let y = 0; y < scale; y++) {
        for (let x = 0; x < scale; x++) {
          const i = (((r + quiet) * scale + y) * size + (c + quiet) * scale + x) * 4;
          data[i] = data[i + 1] = data[i + 2] = 0;
        }
      }
    }
  }
  return { data, width: size, height: size };
}
```

```ts
import { LABEL_MM, PT_PER_MM } from '@shared/qrcode';
import { LABEL_FONT_FAMILY } from './fonts';

export interface LogoSource {
  image: CanvasImageSource;
  width: number;
  height: number;
}

/** Gambar yang muat di kotak persegi `boxMm` dengan aspek terjaga dan terpusat. */
export function containRect(srcW: number, srcH: number, boxMm: number) {
  const scale = boxMm / Math.max(srcW, srcH);
  const w = srcW * scale;
  const h = srcH * scale;
  return { dx: (boxMm - w) / 2, dy: (boxMm - h) / 2, w, h };
}

function darkRuns(row: readonly boolean[]): Array<[number, number]> {
  const runs: Array<[number, number]> = [];
  let start = -1;
  row.forEach((dark, index) => {
    if (dark && start < 0) start = index;
    if (!dark && start >= 0) {
      runs.push([start, index - start]);
      start = -1;
    }
  });
  if (start >= 0) runs.push([start, row.length - start]);
  return runs;
}

/** Menggambar label 30 × 30 mm; `pxPerMm` menentukan resolusi (12 = pratinjau, ~23,6 = 600 dpi). */
export function drawLabel(
  ctx: CanvasRenderingContext2D,
  layout: LabelLayout,
  matrix: boolean[][],
  logo: LogoSource | null,
  pxPerMm: number,
): void {
  const side = LABEL_MM * pxPerMm;
  ctx.fillStyle = '#ffffff';
  ctx.fillRect(0, 0, side, side);
  for (const element of layout.elements) {
    if (element.kind === 'qr') {
      const modulePx = (element.sizeMm * pxPerMm) / matrix.length;
      const originX = element.xMm * pxPerMm;
      const originY = element.yMm * pxPerMm;
      ctx.fillStyle = '#000000';
      matrix.forEach((row, r) => {
        const y0 = Math.round(originY + r * modulePx);
        const y1 = Math.round(originY + (r + 1) * modulePx);
        for (const [start, length] of darkRuns(row)) {
          const x0 = Math.round(originX + start * modulePx);
          const x1 = Math.round(originX + (start + length) * modulePx);
          ctx.fillRect(x0, y0, x1 - x0, y1 - y0);
        }
      });
    } else if (element.kind === 'logo' && logo) {
      const back = element.backdropMm * pxPerMm;
      const cx = (element.xMm + element.sizeMm / 2) * pxPerMm;
      const cy = (element.yMm + element.sizeMm / 2) * pxPerMm;
      ctx.fillStyle = '#ffffff';
      ctx.fillRect(cx - back / 2, cy - back / 2, back, back);
      const fit = containRect(logo.width, logo.height, element.sizeMm);
      ctx.drawImage(
        logo.image,
        (element.xMm + fit.dx) * pxPerMm,
        (element.yMm + fit.dy) * pxPerMm,
        fit.w * pxPerMm,
        fit.h * pxPerMm,
      );
    } else if (element.kind === 'text') {
      ctx.fillStyle = '#000000';
      ctx.font = `${element.bold ? 600 : 400} ${(element.sizePt / PT_PER_MM) * pxPerMm}px ${LABEL_FONT_FAMILY}, sans-serif`;
      ctx.textAlign = 'center';
      ctx.textBaseline = 'alphabetic';
      ctx.fillText(element.text, element.centerMm * pxPerMm, element.baselineMm * pxPerMm);
    }
  }
}

export function renderLabelCanvas(
  layout: LabelLayout,
  matrix: boolean[][],
  logo: LogoSource | null,
  pxPerMm: number,
): HTMLCanvasElement {
  const canvas = document.createElement('canvas');
  const side = Math.round(LABEL_MM * pxPerMm);
  canvas.width = side;
  canvas.height = side;
  const ctx = canvas.getContext('2d');
  if (!ctx) throw new Error('Peramban tidak mendukung pengolahan gambar');
  drawLabel(ctx, layout, matrix, logo, pxPerMm);
```

```ts
import fontkit from '@pdf-lib/fontkit';
import type { LabelLayout } from '@shared/qrcode';
import { LABEL_MM, PT_PER_MM, SHEET, sheetCells } from '@shared/qrcode';
import { PDFDocument, rgb } from 'pdf-lib';
import { containRect } from './render-canvas';

export interface PdfFonts {
  regular: ArrayBuffer | Uint8Array;
  bold: ArrayBuffer | Uint8Array;
}

function darkRuns(row: readonly boolean[]): Array<[number, number]> {
  const runs: Array<[number, number]> = [];
  let start = -1;
  row.forEach((dark, index) => {
    if (dark && start < 0) start = index;
    if (!dark && start >= 0) {
      runs.push([start, index - start]);
      start = -1;
    }
  });
  if (start >= 0) runs.push([start, row.length - start]);
  return runs;
}

/** Satu label 30 × 30 mm sebagai PDF vektor (QR = kotak, teks = font tersemat). */
async function buildLabelPdf(
  layout: LabelLayout,
  matrix: boolean[][],
  logoPng: Uint8Array | null,
  fonts: PdfFonts,
): Promise<Uint8Array> {
  const doc = await PDFDocument.create();
  doc.registerFontkit(fontkit);
  const regular = await doc.embedFont(fonts.regular, { subset: true });
  const bold = await doc.embedFont(fonts.bold, { subset: true });
  const side = LABEL_MM * PT_PER_MM;
  const page = doc.addPage([side, side]);
  const black = rgb(0, 0, 0);
  const white = rgb(1, 1, 1);
  page.drawRectangle({ x: 0, y: 0, width: side, height: side, color: white });
  const logoImage = logoPng ? await doc.embedPng(logoPng) : null;
  for (const element of layout.elements) {
    if (element.kind === 'qr') {
      const cell = (element.sizeMm * PT_PER_MM) / matrix.length;
      matrix.forEach((row, r) => {
        for (const [start, length] of darkRuns(row)) {
          page.drawRectangle({
            x: element.xMm * PT_PER_MM + start * cell,
            y: side - element.yMm * PT_PER_MM - (r + 1) * cell,
            width: length * cell,
            height: cell,
            color: black,
          });
        }
      });
    } else if (element.kind === 'logo' && logoImage) {
      const back = element.backdropMm * PT_PER_MM;
      const cx = (element.xMm + element.sizeMm / 2) * PT_PER_MM;
      const cy = side - (element.yMm + element.sizeMm / 2) * PT_PER_MM;
      page.drawRectangle({ x: cx - back / 2, y: cy - back / 2, width: back, height: back, color: white });
      const fit = containRect(logoImage.width, logoImage.height, element.sizeMm);
      page.drawImage(logoImage, {
        x: (element.xMm + fit.dx) * PT_PER_MM,
        y: side - (element.yMm + fit.dy + fit.h) * PT_PER_MM,
        width: fit.w * PT_PER_MM,
        height: fit.h * PT_PER_MM,
      });
    } else if (element.kind === 'text') {
      const font = element.bold ? bold : regular;
      const width = font.widthOfTextAtSize(element.text, element.sizePt);
      page.drawText(element.text, {
        x: element.centerMm * PT_PER_MM - width / 2,
        y: side - element.baselineMm * PT_PER_MM,
        size: element.sizePt,
        font,
        color: black,
      });
    }
  }
  return doc.save();
}

/**
 * Lembar 300 × 420 mm: label dibuat SEKALI lalu dirujuk 140 kali (`embedPdf`), sehingga berkas tetap kecil;
 * garis potong tipis di setiap batas sel.
 */
export async function buildSheetPdf(
  layout: LabelLayout,
  matrix: boolean[][],
  logoPng: Uint8Array | null,
  fonts: PdfFonts,
): Promise<Uint8Array> {
  const labelBytes = await buildLabelPdf(layout, matrix, logoPng, fonts);
  const sheet = await PDFDocument.create();
  const [embedded] = await sheet.embedPdf(labelBytes);
  if (!embedded) throw new Error('Label gagal disematkan');
  const width = SHEET.widthMm * PT_PER_MM;
  const height = SHEET.heightMm * PT_PER_MM;
  const side = LABEL_MM * PT_PER_MM;
  const page = sheet.addPage([width, height]);
  for (const cell of sheetCells()) {
    page.drawPage(embedded, {
      x: cell.xMm * PT_PER_MM,
      y: height - (cell.yMm + LABEL_MM) * PT_PER_MM,
      width: side,
      height: side,
    });
  }
  const line = { thickness: 0.25, color: rgb(0.45, 0.45, 0.45) };
  for (let c = 0; c <= SHEET.columns; c++) {
    const x = c * side;
    page.drawLine({ start: { x, y: 0 }, end: { x, y: height }, ...line });
  }
  for (let r = 0; r <= SHEET.rows; r++) {
    const y = height - r * side;
    page.drawLine({ start: { x: 0, y }, end: { x: width, y }, ...line });
  }
  return sheet.save();
}
```

```ts
export function bytesToBase64(bytes: Uint8Array): string {
  let binary = '';
  for (let i = 0; i < bytes.length; i += 0x8000) {
    binary += String.fromCharCode(...bytes.subarray(i, i + 0x8000));
  }
  return btoa(binary);
}

export function base64ToBytes(base64: string): Uint8Array {
  const binary = atob(base64);
  const bytes = new Uint8Array(binary.length);
  for (let i = 0; i < binary.length; i++) bytes[i] = binary.charCodeAt(i);
  return bytes;
}

function canvasToBlob(canvas: HTMLCanvasElement): Promise<Blob> {
  return new Promise((resolve, reject) =>
    canvas.toBlob((blob) => (blob ? resolve(blob) : reject(new Error('Gagal membuat PNG'))), 'image/png'),
  );
}

/** Menghasilkan PDF lembar dan PNG label tunggal (base64). Melempar bila isi melebihi kanvas 3 × 3 cm. */
export async function renderExportFiles(
  design: ExportDesign,
  logo: ExportLogo | null,
): Promise<{ pdfBase64: string; pngBase64: string }> {
  const [fonts] = await Promise.all([loadLabelFonts(), registerCanvasFonts()]);
  const matrix = qrMatrix(design.link);
  const layout = layoutLabel(
    {
      title: design.title,
      subtitle: design.subtitle,
      footer: design.footer,
      hasLogo: logo !== null,
      layout: design.layout,
      qrModules: matrix.length,
    },
    createCanvasMeasure(),
  );
  if (layout.overflow) throw new Error('Isi label melebihi kanvas 3 × 3 cm; perbaiki ukuran atau teks');
  let logoSource = null;
  let logoPng: Uint8Array | null = null;
  if (logo) {
    const bitmap = await createImageBitmap(
      new Blob([base64ToBytes(logo.base64)], { type: logo.mime }),
    );
    logoSource = { image: bitmap, width: bitmap.width, height: bitmap.height };
    // pdf-lib hanya menyematkan PNG/JPEG: ubah logo (mis. WebP) menjadi PNG berlatar transparan.
    const logoCanvas = document.createElement('canvas');
    logoCanvas.width = bitmap.width;
    logoCanvas.height = bitmap.height;
    logoCanvas.getContext('2d')?.drawImage(bitmap, 0, 0);
    logoPng = new Uint8Array(await (await canvasToBlob(logoCanvas)).arrayBuffer());
  }
  const pngCanvas = renderLabelCanvas(layout, matrix, logoSource, PNG_PX_PER_MM);
  const pngBytes = new Uint8Array(await (await canvasToBlob(pngCanvas)).arrayBuffer());
  const pdfBytes = await buildSheetPdf(layout, matrix, logoPng, fonts);
  return { pdfBase64: bytesToBase64(pdfBytes), pngBase64: bytesToBase64(pngBytes) };
}
```

```ts
export function saveBase64File(file: QrFileDto): void {
  const blob = new Blob([base64ToBytes(file.base64)], { type: file.mime });
  const url = URL.createObjectURL(blob);
  const link = document.createElement('a');
  link.href = url;
  link.download = file.filename;
  document.body.appendChild(link);
  link.click();
  link.remove();
  URL.revokeObjectURL(url);
```

```tsx
import { drawLabel } from '../lib/render-canvas';

const PREVIEW_PX_PER_MM = 12;
const PLACEHOLDER_LINK = 'https://contoh.com';

export interface LabelPreviewProps {
  title: string;
  subtitle: string;
  footer: string;
  link: string;
  layout: QrLayout;
  /** URL gambar logo (data URL) atau `null`. */
  logoUrl: string | null;

/** Pengukur teks: cadangan dahulu, berganti ke pengukur canvas setelah font label siap. */
export function useLabelMeasure() {
  const [measure, setMeasure] = useState(() => fallbackMeasure);
  useEffect(() => {
    let alive = true;
    registerCanvasFonts()
      .then(() => {
        if (alive) setMeasure(() => createCanvasMeasure());
      })
      .catch(() => undefined);
    return () => {
      alive = false;
    };
  }, []);
  return measure;
}

/** Pratinjau realtime label 3 × 3 cm: tata letak dihitung ulang tiap isi/ukuran berubah. */
export function LabelPreview({ title, subtitle, footer, link, layout, logoUrl }: LabelPreviewProps) {
  const measure = useLabelMeasure();
  const canvasRef = useRef<HTMLCanvasElement>(null);
  const [logo, setLogo] = useState<HTMLImageElement | null>(null);
  const linkText = link.trim() === '' ? PLACEHOLDER_LINK : link.trim();
  const matrix = useMemo(() => qrMatrix(linkText), [linkText]);
  const computed = useMemo(
    () =>
      layoutLabel(
        { title, subtitle, footer, hasLogo: logo !== null, layout, qrModules: matrix.length },
        measure,
      ),
    [title, subtitle, footer, logo, layout, matrix, measure],
  );

  useEffect(() => {
    if (!logoUrl) {
      setLogo(null);
      return;
    }
    let alive = true;
    const image = new Image();
    image.onload = () => {
      if (alive) setLogo(image);
    };
    image.onerror = () => {
      if (alive) setLogo(null);
    };
    image.src = logoUrl;
    return () => {
      alive = false;
    };
  }, [logoUrl]);

  useEffect(() => {
    const context = canvasRef.current?.getContext('2d');
    if (!context) return;
    drawLabel(
      context,
      computed,
      matrix,
      logo ? { image: logo, width: logo.naturalWidth, height: logo.naturalHeight } : null,
      PREVIEW_PX_PER_MM,
    );
  }, [computed, matrix, logo]);

  return (
    <div className="space-y-2">
      <canvas
        ref={canvasRef}
        width={30 * PREVIEW_PX_PER_MM}
        height={30 * PREVIEW_PX_PER_MM}
        aria-label="Pratinjau label 3 × 3 cm"
        className="rounded border bg-white shadow-sm"
        style={{ width: '30mm', height: '30mm', minWidth: 180, minHeight: 180 }}
      />
      {link.trim() === '' ? (
        <p className="text-xs text-muted-foreground">Isi link untuk melihat QR yang sebenarnya.</p>
      ) : null}

      {computed.tooDense ? (
        <p className="text-sm text-amber-600 dark:text-amber-400">
          QR terlalu padat ({computed.moduleMm.toFixed(2)} mm per modul): pendekkan link atau perbesar QR agar mudah
          dipindai.
        </p>
      ) : null}
    </div>
  );
}
```

```tsx
/** Sumber link dari PDF yang diunggah ke Drive; link QR = URL berbagi berkas. */
export function PdfSourceField({ document, onDocument, onUpload }: PdfSourceFieldProps) {
  const [pending, setPending] = useState<File | null>(null);
  const [error, setError] = useState<string | null>(null);
  const [busy, setBusy] = useState(false);
  const [copied, setCopied] = useState(false);
  const replacing = document !== null;

  function choose(file: File | undefined) {
    setError(null);
    if (!file) return;
    if (file.type !== 'application/pdf') {
      setError('Hanya berkas PDF yang dapat diunggah');
      return;
    }
    if (file.size > QR_LIMITS.documentMaxBytes) {
      setError('Ukuran PDF maksimal 10 MB');
      return;
    }
    setPending(file);
  }

    if (!pending) return;
    setBusy(true);
    try {
      onDocument(await onUpload(pending, document?.id));
      setPending(null);
    } catch (caught) {
      setError(caught instanceof Error ? caught.message : 'Gagal mengunggah PDF');
      setPending(null);
    } finally {
      setBusy(false);
    }
  }

        <Input
          id="qr-pdf-file"
          type="file"
          accept="application/pdf"
          disabled={busy}

            choose(event.target.files?.[0]);
            event.target.value = '';

          <div className="flex gap-2">
            <Input id="qr-pdf-link" readOnly value={document.link} />
            <Button
              type="button"
              variant="outline"
              onClick={() => {
                void navigator.clipboard?.writeText(document.link);
                setCopied(true);
              }}
            >
              {copied ? 'Tersalin' : 'Salin'}
            </Button>
          </div>
        </div>
      ) : null}
      <Dialog open={pending !== null} onOpenChange={(open) => (open ? undefined : setPending(null))}>

  );
```

```tsx
                </form.Field>
              ) : (
                <form.Field name="documentId">
                  {(field) => (

                      <FieldError errors={[...field.state.meta.errors, fieldErrors?.documentId]} />
                    </div>
                  )}
                </form.Field>
              )
            }
          </form.Subscribe>
        </Section>

        <Section title="Logo di tengah QR">
          <form.Field name="logoFileId">

              <div className="space-y-1.5">
                <LogoField value={field.state.value} onChange={field.handleChange} designs={designs} />
                <FieldError errors={[...field.state.meta.errors, fieldErrors?.logoFileId]} />
              </div>
            )}
          </form.Field>
        </Section>

                        <Input
                          id={id}

                          step={range.step}
                          min={range.min}
                          max={range.max}
                          value={Number.isNaN(field.state.value[key]) ? '' : field.state.value[key]}
                          aria-invalid={layoutRangeMessage(key, field.state.value[key]) ? true : undefined}
                          onChange={(event) =>
                            field.handleChange({
                              ...field.state.value,
                              [key]: event.target.value === '' ? Number.NaN : Number(event.target.value),
                            })
                          }
                        />

                          <p className="text-sm text-destructive">{layoutRangeMessage(key, field.state.value[key])}</p>

                    );
                  })}
                </div>

        </Section>

        {submitError ? (
          <p role="alert" className="text-sm text-destructive">
            {submitError}
          </p>

        <div className="flex flex-wrap gap-2">

            {(submitting) => (

              sheetOpen={sheetOpen}
              onSheetOpenChange={setSheetOpen}

          )}
        </form.Subscribe>
      </aside>
    </form>
  );
}
```

```ts
/** Isi berkas sebagai base64 murni (tanpa awalan data URL). */
export function fileToBase64(file: Blob): Promise<string> {
  return new Promise((resolve, reject) => {
    const reader = new FileReader();
    reader.onerror = () => reject(reader.error ?? new Error('Gagal membaca berkas'));
    reader.onload = () => resolve(String(reader.result).split(',')[1] ?? '');
    reader.readAsDataURL(file);
  });
}
```

```tsx
  DialogContent,
  DialogDescription,
  DialogFooter,
  DialogHeader,
  DialogTitle,
} from '@/components/ui/dialog';

export interface ExportDialogProps {
  design: QrDesignDto;
  open: boolean;
  onOpenChange: (open: boolean) => void;
  /** Membuat berkas lalu menyimpannya; melempar bila gagal (pesan ditampilkan di dialog). */
  onConfirm: () => Promise<void>;

export function ExportDialog({ design, open, onOpenChange, onConfirm }: ExportDialogProps) {
  const [busy, setBusy] = useState(false);
  const [error, setError] = useState<string | null>(null);
  const again = design.exportedAt !== '';

  async function confirm() {
    setBusy(true);
    setError(null);
    try {
      await onConfirm();
      onOpenChange(false);
    } catch (caught) {
      setError(caught instanceof Error ? caught.message : 'Ekspor gagal');
    } finally {
      setBusy(false);
    }
  }

  return (
    <Dialog open={open} onOpenChange={(next) => (busy ? undefined : onOpenChange(next))}>
      <DialogContent>
        <DialogHeader>
          <DialogTitle>{again ? 'Ekspor ulang ke Drive?' : 'Simpan hasil ke Drive?'}</DialogTitle>
          <DialogDescription>
            Dua berkas dibuat untuk "{design.title}": PDF lembar 10 × 14 (300 × 420 mm, garis potong) dan PNG label
            3 × 3 cm. Keduanya disimpan di folder Drive "QC App QR".
          </DialogDescription>
        </DialogHeader>
        {again ? (
          <p className="rounded-md border border-amber-500/50 bg-amber-500/10 p-3 text-sm">
            Ekspor ulang menimpa berkas lama (diekspor {design.exportedAt} oleh {design.exportedBy}). Berkas lama
            dipindah ke tempat sampah Drive dan tidak dapat dipakai lagi dari aplikasi.
          </p>
        ) : null}
        {error ? (
          <p role="alert" className="text-sm text-destructive">
            {error}
          </p>
        ) : null}
        <DialogFooter>
          <Button variant="outline" disabled={busy} onClick={() => onOpenChange(false)}>
            Batal
          </Button>
          <Button disabled={busy} onClick={() => void confirm()}>
            {busy ? 'Memproses…' : again ? 'Timpa dan simpan' : 'Simpan ke Drive'}
          </Button>
        </DialogFooter>
      </DialogContent>
    </Dialog>
  );
}
```

```tsx
// web/src/routes/_app/qrcode/new.tsx
import { useSuspenseQuery } from '@tanstack/react-query';
import { createFileRoute, useNavigate } from '@tanstack/react-router';
import { useState } from 'react';
import { toast } from 'sonner';
import { describeError } from '@/lib/rpc/describe-error';
import { pickFieldErrors } from '@/modules/access/lib/field-errors';
import { requirePermission } from '@/modules/auth/permissions';
import { QrDesignForm } from '@/modules/qrcode/components/qr-design-form';
import { qrDesignsQueryOptions, useSaveQrDesign } from '@/modules/qrcode/queries';
import type { QrFieldErrors, QrFormOutput } from '@/modules/qrcode/schemas';
import { QR_FIELD_KEYS, toDuplicateDefaults, toQrFormDefaults, toSaveQrDesignInput } from '@/modules/qrcode/schemas';

export const Route = createFileRoute('/_app/qrcode/new')({
  validateSearch: (search: Record<string, unknown>): { from?: string } =>
    typeof search.from === 'string' ? { from: search.from } : {},
  beforeLoad: ({ context }) => requirePermission(context.queryClient, 'qrcode', 'edit'),
  loader: ({ context }) => context.queryClient.ensureQueryData(qrDesignsQueryOptions()),
  component: NewQrDesignPage,
});

function NewQrDesignPage() {
  const { from } = Route.useSearch();
  const navigate = useNavigate();
  const { data: designs } = useSuspenseQuery(qrDesignsQueryOptions());
  const save = useSaveQrDesign();
  const source = from ? designs.find((design) => design.id === from) : undefined;
  const [submitError, setSubmitError] = useState<string | null>(null);
  const [fieldErrors, setFieldErrors] = useState<QrFieldErrors>({});

  async function handleSubmit(values: QrFormOutput) {
    setSubmitError(null);
    setFieldErrors({});
    try {
      await save.mutateAsync(toSaveQrDesignInput(values));
      toast.success('Konfigurasi disimpan');
      await navigate({ to: '/qrcode' });
    } catch (error) {
      const picked = pickFieldErrors(error, QR_FIELD_KEYS);
      if (Object.keys(picked).length > 0) setFieldErrors(picked);
      else setSubmitError(describeError(error));
    }
  }

  return (
    <div className="max-w-5xl space-y-4">
      <h1 className="text-2xl font-semibold">{source ? 'Duplikat konfigurasi' : 'Konfigurasi QR baru'}</h1>
      <QrDesignForm
        defaultValues={source ? toDuplicateDefaults(source) : toQrFormDefaults()}
        initialDocument={
          source?.linkSource === 'pdf'
            ? { id: source.documentId, name: source.documentName, link: source.link, uses: source.documentUses }
            : null
        }
        designs={designs}
        submitError={submitError}
        fieldErrors={fieldErrors}
        onSubmit={handleSubmit}
        onCancel={() => void navigate({ to: '/qrcode' })}
      />
    </div>
  );
}
```
